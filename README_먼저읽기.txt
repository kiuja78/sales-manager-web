영업관리 시스템 WEB V1.0 - 1차 테스트판
======================================

목적
----
현재 사용자용 V10.25의 화면과 계산 로직을 최대한 그대로 유지하면서
Windows 설치 없이 브라우저에서 실행할 수 있는지 확인하는 1차 웹 버전입니다.

현재 구현
---------
1. Windows / Mac 브라우저에서 실행 가능
2. 기존 영업현황, 접수리스트, 경영평가, 급여계산 등 UI/계산 로직 유지
3. 엑셀 가져오기: 브라우저에서 직접 파싱
4. PWA 기본 구조 포함 - 웹에 올리면 앱처럼 설치 가능
5. 현재 데이터 저장은 브라우저 로컬 저장소를 사용

중요
----
이 1차 테스트판은 '웹 화면/기능 호환성 테스트'용입니다.
현재 단계에서는 PC와 Mac 사이 데이터가 자동 동기화되지 않습니다.

다음 단계
---------
Supabase 연결 후:
- 회사 PC / 집 PC / Mac에서 동일 데이터 실시간 공유
- 로그인
- 온라인 자동 저장
- 온라인 백업
- 설치/SETUP 없이 업데이트

로컬 테스트
-----------
Sales_Manager_WEB_V1.0 폴더의 index.html을 더블클릭하면 됩니다.

웹에 올렸을 때
-------------
GitHub Pages / Netlify / Vercel 같은 정적 호스팅에 폴더 내용을 올리면
주소로 접속할 수 있습니다.
